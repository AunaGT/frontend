Centered isolated artwork with modest breathing room. Genuinely transparent background with clean alpha, no drawn checkerboard and no solid rectangle. No text, no letters, no numbers, no logo, no watermark, no people, no faces, no plus badge or UI controls. This is the image asset only, not a webpage.
