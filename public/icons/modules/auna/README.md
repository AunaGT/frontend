# Iconos de módulos Auna

Iconos SVG para los 22 módulos visibles del ERP. Cada uno es una ilustración compacta dentro de una tarjeta redondeada con volumen suave; combina el azul marino (`#172033`) y naranja (`#F97316`) de Auna con acentos secundarios controlados. No llevan texto.

Los nombres de archivo corresponden al módulo y se cargan desde `src/components/icons/CustomIcons.tsx`. La lámina `contact-sheet.svg` muestra la colección. `scanner.svg` permanece en la carpeta anterior porque el escáner es una acción de producto, no un módulo del catálogo.
